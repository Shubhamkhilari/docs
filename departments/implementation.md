# Implementation & Delivery

## Overview

- Mostly located in Bangalore, serving all regions
- Manages all new client onboarding, project management, and implementation
- Works across all products — no product or geography bifurcation

---

## What the Team Does

- Client UAT and go-lives within SLAs
- Liaison with clients to gather requirements
- Manage change requests and delivery timelines
- Manage internal stakeholders for client requirements
- Manage first billings of clients
- Deliver as per client SOW (Statement of Work)
- Handle special requirements: custom features, customizations, on-premise deployment, language requirements, and other enterprise-level needs

---

## Implementation Flow

```
Hunting team acquires new client
→ Client onboarding by Implementation team
→ Client goes to CSM team after going live
→ Farming team works on account expansion
→ Renewal
```

## What Makes Implementation Easier or Harder

**Easier:**
- Existing HRIS with API access
- SSO enabled
- Collaboration tools (Slack/MS Teams) in place
- Clean, centralized employee data
- Assigned HR/IT owner

**Harder:**
- No centralized HR system
- Strict data residency or on-premise requirements
- Custom in-house HR platforms
- Slow internal IT change cycles
