# Tech & QA

## Overview

- Centrally located in Bangalore
- Each product has its own tech & QA team (Empuls, Plum, Loyalife), though they collaborate
- Responsible for on-time feature delivery, security, DevOps, AI features, code review

---

## What Tech Teams Are Responsible For

- On-time feature and client-related requirement delivery
- Security and compliance
- DevOps and infrastructure
- AI features and integration
- Code review standards

---

## How Tech Teams Work

- Tech always takes feature requests **from the product team only** — this ensures no wrong feature or priority reaches engineering
- Works closely with product, design, and project management teams

---

## Engineering Process

```
Feature request from product team (or tech debt)
→ Sprint planning
→ Development
→ QA & UAT
→ Deployment / Production Release
```
