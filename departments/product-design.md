# Product Management & Design

## Overview

- Centrally located in Bangalore/NCR
- Each product has its own product team (Empuls, Plum, Loyalife), though they collaborate
- Works across all stakeholders: sales, marketing, tech, clients, CS, CSM, and project teams

---

## What Product Teams Are Responsible For

- Managing product roadmap, features, and client requirements
- UI/UX design and experience
- Competitive intelligence
- Product demos and documentation
- Product growth and monetization
- Revenue growth through end users, existing account admins, feature upsell
- AAARRR metrics, DAU, MAU, and other growth metrics

---

## Product Development Process

```
Feature request (from existing client / new sales / competition)
→ Requirement definition
→ Development coordination
→ QA & UAT
→ Production Release
→ Feedback loop
→ Growth (B2B & B2B2C)
```

## Key Terms

| Term | Description |
|---|---|
| PRD | Product Requirement Document — describes features and requirements |
| Sprint | Short development cycle for completing tasks |
| Backlog | List of product features or issues yet to be planned |
| Release | Deployment of new features or updates |
| UAT | User Acceptance Testing — validation before release |
| Bug/Defect | An issue requiring correction in the system |
| Tech Debt | Pending technical improvements |
