# Glossary

Key terminology used across Xoxoday — organized by domain.

---

## Sales & Revenue Terminology

| Term | Definition |
|---|---|
| ARR (Annual Recurring Revenue) | The yearly value of recurring subscription revenue from customers |
| MRR (Monthly Recurring Revenue) | The monthly recurring subscription revenue from customers |
| ACV (Annual Contract Value) | The annualized value of a customer contract, excluding one-time fees |
| TCV / LTV (Total Contract Value) | The total value of a contract over its entire duration |
| GMV (Gross Merchandise Value) | The total value of rewards or catalog items purchased through the platform |
| GMV Margin | Revenue earned from margins on reward catalog transactions |
| Breakage / Expiry | Revenue generated when rewards are purchased but not redeemed |
| Net Revenue | Total revenue from SaaS subscriptions, GMV margin, implementation fees, and breakage |
| NRR (Net Revenue Retention) | Revenue retained from existing customers after accounting for expansion and churn |
| GRR (Gross Revenue Retention) | Revenue retained from customers excluding expansions |
| Churn | Loss of customers or recurring revenue due to cancellations |
| Contraction | Reduction in revenue from existing customers |
| Upsell | Increasing revenue by selling higher-value or new product offerings to existing customers |
| Cross-sell | Selling additional products, a new geography, or a new department to an existing customer |
| Deal | A potential revenue opportunity under discussion with a client |
| Pipeline | The total value of active sales opportunities being pursued |
| Win Rate | Percentage of deals successfully closed |
| Lead | A potential customer who has shown interest |
| Contact | An individual associated with a potential or existing customer account |
| MQL (Marketing Qualified Lead) | A lead qualified by marketing based on engagement signals |
| SQL (Sales Qualified Lead) | A lead confirmed by sales as ready for conversion efforts |
| BANT | Budget, Authority, Need, Timeline — qualification framework |
| Deal Desk | Internal process for reviewing large or complex deals across stakeholders |
| DRI (Directly Responsible Individual) | Single person accountable for driving a decision or outcome |

## Rewards, Catalog & Gift Card Terminology

| Term | Definition |
|---|---|
| Catalog | The collection of rewards, gift cards, experiences, and merchandise available on the platform |
| Vendor | A partner providing rewards or services listed in the catalog |
| SKU (Stock Keeping Unit) | A unique identifier for a specific reward or product in the catalog |
| Vendor Margin | Revenue earned from negotiated pricing differences with vendors |
| Procurement | Process of sourcing and onboarding vendors and rewards |
| Catalog Coverage | Breadth of reward options available across geographies |
| Redemption | The process of a user claiming or using a reward |
| Redemption Rate | Percentage of issued rewards that are redeemed |
| Fulfillment | Process of delivering rewards to end users |
| Voucher Issuance | Creation and distribution of digital reward codes |
| Delivery SLA | Time commitment for reward fulfillment |
| Closed Loop Gift Card | A gift card redeemable at a specific brand only |
| Open Loop Gift Card | A prepaid card usable across multiple merchants |
| Reward Wallet | A digital balance allocated to users for redeeming rewards |
| Wallet Funding | Process of loading funds into a customer's reward wallet |
| Float | Funds held temporarily before redemption |
| Liability Balance | Outstanding value of issued but unused rewards |
| Breakage / Expiry Revenue | Revenue recognized from unused rewards |
| On-Generation Model | Wallet deducted at the time of reward issuance |
| On-Redemption Model | Wallet deducted only when the end user redeems the reward |
| Xoxo Points | Reward points distributed via Plum |
| Xoxo Codes | Alphanumeric reward codes distributed via Plum |
| Xoxo Links | Unique reward redemption links distributed via Plum |

## Loyalty Terminology

| Term | Definition |
|---|---|
| Closed Loop | Rewards earned and burned within a specific brand or small set of options |
| Open Loop | Rewards redeemable anywhere — maximum flexibility |
| Semi-Closed | Earn from one place, burn at select places |
| Coalition Loyalty | Multiple brands sharing one loyalty ecosystem |
| Tier | Loyalty program level (e.g., Silver, Gold, Platinum) |
| Accrual | Earning of loyalty points/rewards |
| Redemption | Using earned points/rewards |
| Breakage | Unredeemed points that expire or are forfeited |
| CLTV (Customer Lifetime Value) | Total revenue expected from a customer over their relationship |
| MDF (Market Development Fund) | Budget provided to partners for joint marketing activities |
